# Echo

> A personal AI assistant for grown-ups. Voice in, voice out, vision when it helps, memory across years. Runs on your existing Claude Pro, ChatGPT Plus, or Gemini Pro subscription. No API keys, no separate bills, no data leaving your machine without your say-so.

Echo is the open-source, cross-platform, local-first Jarvis you actually own.

- **Bring your own AI subscription.** Any of them. Claude Pro, ChatGPT Plus, Gemini Pro, Ollama running locally, anything that ships an official CLI or sanctioned local agent. **Never an API key. Never a separate bill.** One click in the setup wizard authorises whichever you have.
- Voice loop with sub-second turn time
- Brain-agnostic router that dispatches each prompt to whichever brain you have authorised, picking the best fit by capability + remaining quota
- Translucent multi-monitor HUD
- One-click OAuth for calendar, mail, music, notes, tasks, smart home, finance
- Memory store across sessions, signal-ranked recall
- macOS, Windows, Linux
- MIT licensed

The full brain-authorisation philosophy lives in **[ANY-BRAIN.md](./ANY-BRAIN.md)**.

This repository is in the planning stage. The full plan lives in **[PLAN.md](./PLAN.md)**.

## Why

There is no shortage of AI assistant apps. Every one of them locks you into a provider, sends your data through a server you do not own, charges a second subscription, or breaks the moment a model gets renamed. Echo is the assistant you would actually trust to run in the background of your life.
