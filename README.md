<br/>

A personal AI assistant that runs on the subscription you already pay for. Voice. Vision. Memory. A translucent multi-monitor HUD. **No API keys. No second bill. Local-first. Open source.**

It speaks. It listens. It sees. It remembers. It does what you ask, with the tools you give it. It runs on macOS, Windows and Linux from one codebase. It is free, open source, and MIT licensed.

<br/>

## The three promises

**No API keys, ever.** Echo runs on whatever AI subscription you already pay for. Claude Pro, ChatGPT Plus, Gemini Pro, or a local Ollama install. You bring the brain. Echo has nothing else to bill you for.

**Local-first by design.** Voice loop, memory store, skills, HUD. Everything sits on your machine. No proxy in the middle.

**One subscription, full assistant.** If you have a Pro plan, you have a full Jarvis. If you run Ollama, you have it for free. There is no recurring fee on top.

<br/>

## Brains you can authorise

| Brain | Subscription | Channel |
|---|---|---|
| Claude Code | Claude Pro or Max | `claude` CLI |
| Codex | ChatGPT Plus, Pro, Team | `codex` CLI |
| Gemini | Google account or Code Assist | `gemini` CLI |
| Ollama | None, runs locally | localhost API |
| LM Studio | None, runs locally | localhost API |
| Anything else | Whatever the provider ships | one adapter file |

<br/>

## At launch

Wake-word voice loop. Streaming text-to-speech. A brain router that picks the right model for the task. A translucent multi-monitor HUD with separate roles per display. Memory across years, stored as plain Markdown. OS keychain for every OAuth token. Calendar, mail, music, notes, tasks, home, vision, code awareness, and a proactive scheduler. Single-click OAuth for everything cloud, native bridges for everything local. An MCP skill bus so every skill plugs into other agent hosts too.
